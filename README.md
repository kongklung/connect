# connect

หน้าเว็บสาธารณะของแอป **Kongklung Connect** — นโยบายความเป็นส่วนตัวและหน้าความช่วยเหลือ
ที่ App Store Connect บังคับให้ต้องมี URL จริงตอนส่งแอปเข้ารีวิว

เผยแพร่ด้วย GitHub Pages จาก branch `main` โฟลเดอร์ root ภายใต้บัญชี `kongklung`

**คนละหน้ากับ https://kongklung.github.io/privacy/** ซึ่งเป็นของแอป Android ตัวเก่า
(`com.silverlightthailand.kongklung`) อยู่ใน repo `kongklung/privacy` แยกกัน อย่าแก้ทับกัน

| หน้า | URL |
|---|---|
| หน้าแรก | https://kongklung.github.io/connect/ |
| Privacy Policy | https://kongklung.github.io/connect/privacy/ |
| Support | https://kongklung.github.io/connect/support/ |

ต้นฉบับอยู่ใน `site/` ของ repo `kongklung_flutter_cloud` — **แก้ที่นั่นก่อน แล้วค่อยคัดลอกมาที่นี่**
จะได้ไม่หลุดจากกัน

ไฟล์ `.nojekyll` ห้ามลบ ไม่งั้น GitHub Pages จะใช้ Jekyll ซึ่งข้ามไฟล์ที่ขึ้นต้นด้วย `_`
ทำให้ `_style.css` หาย หน้าเว็บจะไม่มีสไตล์
